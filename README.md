# luci-app-temp-status

Temperature sensors data for the LuCI status page (OpenWrt webUI).

OpenWrt >= 22.03.

**Dependences:** ucode, ucode-mod-fs.

## Installation notes

```sh
sh -c "$(curl -fsSL https://raw.githubusercontent.com/iamxiaojianzheng/luci-app-temp-status/main/install.sh)" || sh -c "$(wget -qO- https://raw.githubusercontent.com/iamxiaojianzheng/luci-app-temp-status/main/install.sh)"
```
